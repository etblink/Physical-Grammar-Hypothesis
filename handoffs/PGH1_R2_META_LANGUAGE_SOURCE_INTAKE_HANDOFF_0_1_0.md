## Strongest source-level conclusions

1. **Institution/general-logic frameworks** can state model-theoretic and translation structure without commitment to one concrete logic.
2. **Logical frameworks** can provide one metalanguage for presenting many object logics, but the object logic remains supplied through signatures, judgments, constants, axioms, or rules.
3. **Categorical logic/type theory** shows that logical operations and proof structure can arise from abstract categorical/fibrational/contextual structure, conditional on that structure.
4. **Structural/substructural proof theory** shows that changing exchange, contraction, weakening, ordering, or related structural principles materially changes derivability and yields different logical systems.
5. **Translation/invariance machinery** can be strong while logical plurality remains; representation robustness does not imply unique logic selection.
