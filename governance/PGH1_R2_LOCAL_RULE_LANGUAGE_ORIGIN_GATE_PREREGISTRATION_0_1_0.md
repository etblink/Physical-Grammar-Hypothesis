## Purpose

The previous gate established that proper local supports can be generated by restricted rule families, but every tested family depends on a rule language, signature, type system, rewrite/coherence premise, or symmetry action whose origin is not yet justified.

This gate asks one level higher:

\[
\boxed{\text{Can the admissible local-rule language itself be fixed non-result-directly?}}
\]

The gate must distinguish:

1. generating a vocabulary;
2. generating formation rules for expressions;
3. generating equations/equivalences among expressions;
4. selecting a particular admissibility predicate/support.

A construction that merely makes arbitrary supports easy to name receives no R2 explanatory credit.

## Candidate M0 — unrestricted primitive adjunction

Negative control.

If arbitrary primitive symbols or predicates may be adjoined with arbitrary interpretations, then for any desired support `R` one may introduce a primitive `P_R` interpreted exactly as `R`.

This can make a target support one-symbol short without explaining it.

```text
M0_EXPECTED = REJECT_UNIVERSAL_ENCODING
```

## Candidate M1 — free / initial language generation

Given a fixed generator/signature package `Sigma`, construct the free term language `T(Sigma)` with only the formation operations required by `Sigma` and no additional equations.

Test whether free/initial generation:

- is canonical conditional on `Sigma`;
- avoids target-result inspection;
- generates any proper support/exclusion not already present in arity/type/formation restrictions of `Sigma`.

Locked expectation to test, not assume:

> a free language provides generativity but adds no equations or semantic exclusions beyond structure already contained in its generators and formation rules.

## Candidate M2 — automorphism-invariant structural language

Given base structure `B`, allow only predicates/relations invariant under `Aut(B)`.

Locked finite tests:

### M2a — pure finite set, binary relations

Let `D` be a finite set with no structure beyond equality and full renaming symmetry `S_D`.

For `|D| >= 2`, classify the orbits of `S_D` on `D^2` and count all invariant binary supports.

Test whether invariance uniquely selects a nontrivial proper support.

### M2b — ternary relations

For `|D| >= 3`, classify the equality-pattern orbits on `D^3` and count invariant ternary supports.

The gate must distinguish reduction of arbitrariness from unique law selection.

## Candidate M3 — compositional-role / type extraction

Attempt to generate a type/interface language from structural participation profiles or constituent incidence already present in accepted PGH artifacts.

Controls:

```text
DO_NOT_TREAT_ARBITRARY_F_AS_A_PHYSICAL_TYPE_SYSTEM
DO_NOT_TREAT_PRESENTATION_POSITION_AS_REPRESENTATION_INDEPENDENT
DO_NOT_DEFINE_TYPES_BY_TARGET_RESPONSE_CLASS
```

The gate must determine whether role-derived typing is genuinely deeper than the arbitrary formation baseline or merely inherits its choices.

## Candidate M4 — coherence language generated by presentation projection

Given a presentation projection

\[
q:P\to I,
\]

generate equations/equivalences from the kernel relation

\[
p\sim_q p' \iff q(p)=q(p').
\]

Test whether this makes the equation language non-arbitrary, or whether the prior underdetermination of `q` (`PGH-FAIL-0004`) simply moves the language-selection burden into the projection.

No physical meaning may be assigned to the kernel merely because it is mathematically canonical conditional on `q`.

## Candidate M5 — minimal common structural core

Consider whether the intersection/common core of all admissible representation-respecting languages yields a unique restricted meta-language.

The gate must test both possibilities:

1. the common core is too weak/trivial to generate proper supports;
2. adding enough structure to regain selectivity reintroduces a choice of primitives/equations/types.

No simplicity or minimum-description claim is allowed without an independently fixed description language.

## Locked theorem T1 — free-language nonselection

For a free term algebra/language on a fixed signature with no equations beyond syntactic formation, test whether distinct well-formed terms remain distinct and whether any semantic/equational exclusion must therefore come from:

- the signature/arity/type formation rules;
- an added quotient/equation/rewrite system;
- an interpretation/semantic predicate.

If yes:

```text
FREE_GENERATIVITY_ALONE = NONSELECTIVE_WITH_RESPECT_TO_EQUATIONAL_LAW
```

## Locked theorem T2 — renaming-invariant relation multiplicity

For a pure finite set `D`:

- on `D^2`, classify full-permutation orbits and invariant supports;
- on `D^3` for `|D| >= 3`, classify full-permutation orbits and invariant supports.

If multiple nontrivial invariant supports exist, then:

```text
FULL_RENAMING_INVARIANCE = ARBITRARITY_REDUCTION_NOT_UNIQUE_RULE_SELECTION
```

## Locked control T3 — primitive-adjunction universal encoding

For arbitrary finite support `R subseteq D^C`, test the construction that adds one primitive predicate `P_R` interpreted as `R`.

The gate must explicitly reject one-symbol descriptions obtained this way as explanatory compression.

## Locked control T4 — projection-kernel relocation

Use the already accepted presentation-projection results to test whether a coherence/equation language generated from `ker(q)` is canonical only relative to `q`, leaving the origin of `q` unresolved.

## No-smuggling firewall

### N1 — target-law retrospection

No language, signature, type system, symmetry group, or projection may be chosen because it reproduces a known physical law, contextuality support, Bell structure, quantum probability pattern, or desired no-go theorem.

### N2 — primitive semantic loading

A primitive symbol whose interpretation is already the target support is a table by another name.

### N3 — free-construction inflation

`FREE`, `INITIAL`, `UNIVERSAL`, or `CANONICAL` are not by themselves scientific selection criteria. A construction must be audited for which inputs were fixed before the universal property applied.

### N4 — symmetry inflation

An invariant language may reduce the candidate space, but neither the symmetry group nor one invariant orbit/support may be privileged without independent justification.

### N5 — inherited arbitrary formation

Any type or role language mechanically extracted from `PGH-GRAM-0002` inherits the universal-table problem unless it can be shown to discard rather than encode arbitrary formation information by an independently justified invariant construction.

### N6 — physical-anchor firewall

The law-free empirical anchor may provide reference labels but not the local admissibility relations the language is meant to generate.
