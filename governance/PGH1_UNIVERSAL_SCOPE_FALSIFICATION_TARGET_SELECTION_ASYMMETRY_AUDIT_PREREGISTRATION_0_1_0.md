## 1. Purpose

`PGH-OBJ-0052` makes a universal physical claim:

```text
FOR_ALL_I_ELIGIBLE_PHYSICAL_RECORD_INTERFACES:
    p_emp(A,B,C) in T_ind
```

The project's target-discovery safeguards were built to prevent favorable-result cherry-picking and false prospective confirmation. The recent repaired metadata search still produced no freezeable target.

The present audit asks whether those safeguards have been interpreted too symmetrically between **support** and **refutation**.

The controlling question is:

```text
IF_PGH_OBJ_0052_IS_UNIVERSAL
AND_A_TARGET_IS_VALIDLY_I_ELIGIBLE
AND_A_TEST_IS_FROZEN_BEFORE_RESPONSE_DATA
MAY_A_TARGET_BE_CHOSEN_OR_CONSTRUCTED_ADVERSARIALLY_BECAUSE_IT_IS_EXPECTED_TO_STRESS_OR_VIOLATE_T_ind
FOR_REFUTATION_ONLY
EVEN_THOUGH_THE_SAME_TARGET_SELECTION_WOULD_BE_INVALID_FOR_POSITIVE_PREDICTIVE_CREDIT?
```

This operation does not select, construct or test such a target. It adjudicates only the methodological asymmetry.

## 5. Mandatory criteria

Each criterion must be adjudicated explicitly.

### F1 — textual empirical-credit asymmetry

Determine whether canonical rules distinguish positive empirical credit from negative refutation, especially:

```text
KNOWN_KP_INCOMPATIBILITY = MAY_REFUTE_A_SUCCESSOR_IF_LOGICALLY_ENTAILED
KNOWN_KP_COMPATIBILITY = ZERO_PROSPECTIVE_CONFIRMATION_CREDIT
FIRST_POSITIVE_EMPIRICAL_CREDIT = PROSPECTIVE_TARGET_REQUIRED
```

### F2 — quantifier structure of physical scope

Determine the consequence of:

```text
S = TRUE
FOR_ALL_I_ELIGIBLE_PHYSICAL_RECORD_INTERFACES
```

A universal physical statement is false if one genuinely I-eligible physical interface has an empirical distribution outside `T_ind`, subject to a qualified statistical/measurement adjudication.

### F3 — formal counterexample availability

Bind `PGH-DER-0033`:

```text
p_star(000) = 1/2
p_star(111) = 1/2
p_star NOT_IN T_ind
```

and its correlated/common-source controls.

The audit must determine whether knowledge of a formal outside-model witness may guide **hostile falsification design** without creating false negative evidence.

### F4 — I-eligibility versus causal/source architecture

Determine whether frozen `I` requires the physical interface itself to instantiate three independent sources.

The candidate package instead states that no scale, regime, causal architecture, laboratory design, independent-source metadata or external physical sector narrows `S`.

### F5 — construction versus discovery

Determine whether `I` logically restricts eligible records to naturally preexisting public datasets, or whether a prospectively documented experimental/instrumental record interface may qualify if it satisfies the same access, identity, binary-field, joint-index and missingness rules before response analysis.

No actual experiment may be designed in this audit.

### F6 — false-positive versus false-negative risk

Assess the epistemic asymmetry:

- selecting a target because it is expected to **survive** can manufacture apparent support;
- selecting a target because it is expected to **break** a universal law cannot by itself establish a false counterexample if the target really is in scope and the preregistered analysis validly rejects the law's model class.

The audit must still protect against measurement artifacts, invalid I-mapping and post-data analysis tuning.

### F7 — known-result quarantine scope

Determine whether quarantine language explicitly governs **positive** credit rather than erasing logically valid negative evidence.

### F8 — survival-credit ceiling for adversarial targets

If adversarial falsification is allowed, determine the status of non-rejection.
