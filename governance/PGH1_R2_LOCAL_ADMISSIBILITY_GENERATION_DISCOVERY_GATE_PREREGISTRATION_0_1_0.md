## Purpose

Discover and classify candidate mechanisms capable of generating proper local admissibility supports

\[
R_C\subsetneq D^C
\]

without importing the target response law, a desired global impossibility, or arbitrary tuple tables.

This operation is discovery and no-smuggling adjudication only. It may identify a candidate family for a later gate, but it may not promote any family to a physical grammar.

## Locked candidate families

### S0 — arbitrary support table

Directly specify `R_C` as a subset of `D^C`.

This is the negative control and is expected to fail explanatory credit.

### S1 — unrestricted local predicate/formula

Define

\[
R_C=\{x\in D^C:P_C(x)\}.
\]

Test whether calling `P_C` a logical rule rather than a table removes universal encoding.

### S2 — grammar-internal equational support

Use a fixed algebraic signature already supplied by a candidate grammar and admit tuples satisfying equations between grammar terms.

The audit must distinguish:

- equations forced by already justified grammar structure;
- equations freely chosen because they reproduce desired exclusions.

### S3 — typing/interface matching support

Admit tuples only when grammar-derived type/interface data match compositionally.

The audit must determine whether the type system is itself derived or simply another support table in disguise.

### S4 — derivational coherence / rewrite-consistency support

Admit local tuples only when alternative grammar derivations agree, normalize consistently, or satisfy a locked coherence criterion.

The audit must preserve the existing physical-bridge ceiling on coherence results.

### S5 — symmetry/invariance-generated support

Admit tuples by a criterion invariant under a grammar-internal automorphism or symmetry action.

The symmetry action must be fixed independently of the target support.

### S6 — empirical/operational support

Use observed or theory-known response supports, probability-zero events, possible/impossible tasks, or empirically reconstructed local state spaces.

This is a physical-smuggling control and may not receive R2 explanatory credit merely because the support is compactly described.

## Locked universal-encoding test U1 — finite formula encoding

For finite `C` and finite `D`, let arbitrary

\[
R\subseteq D^C.
\]

Using equality atoms of the form `x_i=d`, test whether the formula

\[
\Phi_R(x)=\bigvee_{r\in R}\bigwedge_{i\in C}(x_i=r_i)
\]

has exactly `R` as its model set.

If yes, then the statement

> local supports are generated by formulas

is vacuous unless the allowed formula language, axioms, complexity, or construction rules are independently restricted.

## Locked compactness-control U2

A support description does not receive explanatory credit merely because it is shorter than the explicit tuple list.

The gate must ask whether the description language itself was selected independently of the target support. A new primitive symbol whose interpretation is exactly `R` is a one-token table, not a derivation.
