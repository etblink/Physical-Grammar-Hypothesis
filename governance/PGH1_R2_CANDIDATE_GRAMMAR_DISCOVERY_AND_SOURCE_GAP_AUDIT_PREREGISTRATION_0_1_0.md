## Purpose

The anchored R2 gate established that `PGH-GRAM-0002` is formally useful but insufficient for law exhaustion. This operation therefore does not modify that baseline. It discovers and classifies candidate **principle families** that could later support a new grammar candidate with non-table-driven exclusion power.

The operation is discovery and source-gap adjudication, not candidate selection and not a physical-law derivation.

## Candidate-family acceptance screen

Each lane is evaluated against:

```text
D1_INDEPENDENT_MOTIVATION = principle family is motivated independently of the target physical law it might later constrain
D2_NON_TABLE_DRIVEN_EXCLUSION = compact principle excludes structures without extensional enumeration of forbidden cases
D3_NONVACUOUS_MODEL_VARIATION = both satisfying and violating formal models exist
D4_NO_TARGET_LAW_IMPORT = no known response law, probability law, spacetime law, or target possibility partition is encoded as a premise
D5_ANCHOR_COMPATIBILITY = principle could in principle act downstream of the law-free empirical-reference boundary
D6_PHYSICAL_BRIDGE_NOT_PREASSUMED = physical interpretation remains an explicit future burden rather than being counted as already solved
D7_SOURCE_ADEQUACY = frozen corpus is sufficient to evaluate the family at the present discovery scope
```

A lane may receive:

```text
PRIORITY_A = survives D1-D6 and frozen corpus is adequate for a bounded next-stage formal candidate test
PRIORITY_B = promising but D7 fails because a concrete source gap blocks responsible evaluation
PRIORITY_C = mathematically useful but currently too representational, too weak, or too close to imported physical law for R2 priority
REJECT_AT_DISCOVERY_SCOPE = fails the no-smuggling or non-table-driven screen
```

A priority designation is not physical status and not a grammar selection.

## Universal-encoding firewall

For every surviving lane ask whether an arbitrary target restriction can be encoded by freely choosing the relevant rewrite rules, diagrams, algebraic operations, task set, symmetry group, constraint set, or other input.

If yes, the family receives no R2 credit merely from the fact that the resulting formal system excludes structures. The independently justified origin of the constraining input must remain visible.

## Source-gap protocol

The frozen 37-source corpus must be used first.

Source expansion is justified only if all of the following hold:

1. a candidate lane survives enough of D1-D6 to matter;
2. the existing corpus lacks the primary or authoritative sources needed to adjudicate the lane's exclusion mechanism or independence claim;
3. the missing subject can be named narrowly enough to define a bounded search lane;
4. the gap is not merely a desire for more citations.

If justified, this operation may identify the search lane but must stop before performing the new source intake. External source search requires a separate subsequent operation.
