## Purpose

Perform a severe prior-art/source-bound subtraction on the PGH meta-language-origin problem using only the frozen SG3 corpus.

The adjudication must distinguish four claims:

1. **Meta-framework existence:** one formal framework can represent or organize many logics.
2. **Translation invariance:** different logics/languages can be related while preserving satisfaction, entailment, or structural content.
3. **Structure-relative logic generation:** logical operations/rules can arise from categorical, type-theoretic, proof-theoretic, or other abstract structure.
4. **Rule-package selection:** a non-result-directed principle selects the particular structural/signature/type/equation package that should govern physical admissibility.

Only claim 4 could discharge the current PGH R2 meta-language-origin burden.

## Frozen family tests

### F1 — institutions / general logics

Test whether institution/general-logic machinery:

- abstracts from concrete logics;
- supports translations/comparison;
- supplies a unique object-logic selector.

### F2 — logical frameworks

Test whether LF/equational logical frameworks:

- centralize syntax/judgment/proof infrastructure;
- leave object-logic signatures/rules as input;
- contain any general criterion selecting one object logic.

### F3 — categorical logic/type organization

Test whether categorical/hyperdoctrine/fibration/contextual machinery:

- derives logical operations relative to structural assumptions;
- independently fixes the categorical/type structure itself;
- therefore closes or merely moves the PGH origin burden.

### F4 — structural/substructural proof theory

Test whether structural-rule variation:

- materially changes derivability/logical system;
- is treated as one uniquely derivable package or as a family of alternatives;
- strengthens the claim that structural-rule selection carries substantive formal information.

### F5 — translation/invariance control

Test whether high-quality translation/representation invariance can coexist with genuine logical plurality.

If yes, representation robustness cannot by itself serve as unique meta-language selection.

## Residual-burden test R

A PGH-specific residue survives only if it can be stated without claiming novelty for institutions, logical frameworks, categorical logic, or substructural proof theory.

Candidate residual statement to test, not assume:

> Given a law-free empirical reference boundary, can a representation-robust generative principle produce the **selective structural rule/signature/type package itself**, rather than merely provide a neutral metalanguage in which such packages may be stated, and can that generated package then yield substantive physical admissibility without an independent law set?

The adjudication must separate this from ordinary questions of how to encode or translate logics.
