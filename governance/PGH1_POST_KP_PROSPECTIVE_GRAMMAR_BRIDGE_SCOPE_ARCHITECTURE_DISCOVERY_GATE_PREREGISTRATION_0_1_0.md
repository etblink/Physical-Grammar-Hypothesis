## Purpose

Determine what **prospective candidate architecture** would be required for a future PGH candidate to acquire physical applicability without repeating the post-Kp scope-under\-determination problem.

The gate asks how formal grammar, semantic realization, physical scope/domain membership, and empirical instantiation must be related **before** any future target is discovered or tested.

It does not choose a successor grammar or a physical sector.

The architectural problem is therefore not merely how to make a grammar selective. It is how a selective formal grammar can state **where it applies physically** without placing the substantive physical selection into an auxiliary applicability rule.

## Candidate architecture schema to test

A future physical candidate may need provenance at least as rich as

\[
\mathcal C=(G,J,S,I),
\]

where:

- `G` = formal grammar / generated model class;
- `J` = semantic realization or bridge from formal roles/models to prospective physical records;
- `S` = physical scope/domain-membership rule over candidate empirical systems or instantiations;
- `I` = prospective instantiation/role-assignment protocol used to map an in-scope system to empirical variables before result inspection.

This tuple is a **test schema**, not an adopted successor ontology.

The gate must decide which components may be primitive, generated, universal, or externally anchored without destroying strong-PGH explanatory credit.

## Universal-encoding control at the scope layer

Let `E` be a candidate universe of possible empirical systems/instantiations and let `S:E->{0,1}` be an unrestricted scope predicate.

For every subset `T subseteq E`, define

\[
S_T(e)=1 \iff e\in T.
\]

Therefore an unrestricted scope language can select any desired target subset exactly.

The gate must test the consequence:

```text
UNRESTRICTED_SCOPE_PREDICATE = UNIVERSAL_TARGET_SUBSET_ENCODER
SHORT_OR_NAMED_SCOPE_DESCRIPTION != EARNED_PHYSICAL_APPLICABILITY
```

No mathematical novelty claim is authorized for this elementary observation.

## Architecture families

### F0 — universal physical scope

```text
S(e) = TRUE for every admissible physical instantiation e
```

No separate domain selector is needed. This is maximally exposed to empirical refutation and has minimal auxiliary freedom, but a single valid counterexample has correspondingly strong force.

### F1 — grammar/bridge-internal structural scope

`S` is generated from or logically forced by `G` and/or `J` through type, interface, invariance, or realization conditions fixed before empirical target discovery.

The gate must distinguish genuine internally generated applicability from a semantic restatement of the desired physical result.

### F2 — primitive law-free observational/semantic scope

`S` is anchored in objective physical reference, measurement, record, or interface facts that do not themselves encode response laws or outcome patterns.

This family is potentially compatible with the project's accepted semantic-anchor concessions, but only if scope does not perform the substantive law selection that strong PGH assigns to grammar.

### F3 — independently established physical-sector scope

`S` is defined using pre-existing physical theory, dynamics, effective-regime assumptions, causal laws, equilibrium assumptions, Markov assumptions, scale separation, or other substantive physics.

This may define a scientifically useful effective/modeling domain, but the gate must decide whether it forfeits strong-PGH law-exhaustion credit by importing independent physical law.

### F4 — higher-level grammar / meta-selector scope

A higher-level grammar or type system determines which subgrammar applies to which physical systems.

The gate must apply the existing relocation control: if the meta-selector is unrestricted or primitive in the decisive respects, the scope problem has moved upward rather than been solved.

### F5 — named-sector or taxonomy-only scope

A domain is named or categorized before target testing but without an independently constraining reason why that category is the grammar's physical domain.

The gate must determine whether prospective naming alone earns any explanatory or predictive credit.

### F6 — result-sensitive / fit-defined scope

Scope is defined using observed dependence, goodness-of-fit, conditional-independence behavior, Markovity, residual size, or any statistic entailed by the candidate.

```text
STATUS = HARD_REJECT
```

This is target/result leakage by construction.
