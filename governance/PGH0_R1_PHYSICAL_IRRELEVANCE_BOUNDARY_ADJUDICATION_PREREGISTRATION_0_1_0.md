## Purpose

The residual strong target `PGH-OBJ-0008` currently requires both:

```text
R1 = PHYSICAL_IRRELEVANCE_SELECTOR
R2 = LAW_EXHAUSTION
```

A sequence of completed R1 operations established all of the following without establishing physical privilege:

1. formal equivalence alone does not entail physical equivalence;
2. a context/record semantic anchor can be formally separated from the response law;
3. such an anchor can be conditionally representation robust;
4. a law-free empirical contact signature is formally coherent;
5. a declared empirical seed can be expanded by grammar-derived, response-independent closure;
6. equal-closure seeds can be quotient-identified for closure-factoring structure;
7. no tested general grammar-internal substructure selector avoids nonuniqueness, trivial extremes, or extra selector input, although special asymmetric grammars can possess unique intrinsic proper substructures.

The purpose of this operation is not to invent another selector. It is to adjudicate what that boundary means for the **claim semantics** of residual strong PGH.

## Fixed distinction: reference versus law

The adjudication must distinguish:

### Semantic reference/contact

A primitive semantic item may designate that a formal token is being used to refer to an empirical probe, record, event, or interface.

At current scope, such an item is **law-free** only if it remains compatible with multiple empirically incompatible response laws while held fixed.

### Substantive law/selection

A primitive item is law-like for PGH accounting if it fixes, excludes, weights, or otherwise selects physically allowed responses, possibilities, histories, or empirical regularities.

The following cannot be reclassified as mere reference:

```text
ALLOWED_RESPONSE_RELATION
RESPONSE_FUNCTION
PROBABILITY_OR_WEIGHT_KERNEL
COMPLETE_POSSIBLE_IMPOSSIBLE_TASK_SET
TARGET_DISTINGUISHABILITY_PARTITION
EMPIRICAL_SUCCESS_SELECTOR_USED_AS_AN_INTRINSIC_RULE
```

The distinction is necessary but not sufficient to settle R1.

## Fixed interpretation of the current residual specification

The canonical residual specification states that `PGH-OBJ-0008` requires a physically justified equivalence relation selected by a non-result-directed criterion, and that failure of R1 blocks strong PGH at the corresponding candidate scope.

Therefore the adjudication may **not** declare R1 satisfied merely because a law-free semantic-contact schema exists.

It must separately ask:

```text
Q1 = IS_LAW_FREE_SEMANTIC_REFERENCE_COMPATIBLE_WITH_THE_NO_INDEPENDENT_LAW_CORE?
Q2 = DOES_THAT_COMPATIBILITY_ACTUALLY_SATISFY_R1_AS_CURRENTLY_SPECIFIED?
Q3 = IF_NOT,IS_AN_EXPLICITLY_ANCHORED_SUCCESSOR_A_REAL_REFORMULATION_RATHER_THAN_A_SILENT_REDEFINITION?
Q4 = WOULD_THAT_SUCCESSOR_STILL_LEAVE_A_NONTRIVIAL_R2_LAW_EXHAUSTION_BURDEN?
```

## Locked tests

### T1 — Semantic/law separation test

Determine whether an irreducible empirical-reference primitive can remain fixed while two incompatible response laws vary.

If yes, semantic reference is not logically identical to a substantive law set.

This test concerns category distinction only; it does not establish physical privilege.

### T2 — R1 satisfaction test

Compare the actual R1 requirements in `PGH0_RESIDUAL_STRONG_PGH_SPECIFICATION_0_1_0.md` against the completed R1 record.

R1 may be called satisfied only if a non-result-directed, representation-robust physically justified criterion actually selects the relevant physical irrelevance/equivalence relation.

A merely admissible schema is insufficient.

### T3 — Silent-goalpost control

If the current strong target fails T2, the adjudication may not simply redefine `R1` inside `PGH-OBJ-0008` and call the original target successful.

Any successor that admits irreducible physical reference must receive a new research-object identity and an explicit specification stating what changed.

### T4 — Law-exhaustion preservation test

A successor remains scientifically strong enough to justify future R2 work only if the primitive anchor contains no substantive response/possibility law and the successor continues to require:

```text
NO_INDEPENDENT_SUBSTANTIVE_LAW_SET
SUBSTANTIVE_PHYSICAL_EXCLUSION_FROM_GRAMMAR
NO_SEMANTIC_SMUGGLING
AT_LEAST_ONE_INDEPENDENT_PHYSICAL_RESTRICTION_FROM_GRAMMAR
```

### T5 — Physical-privilege honesty test

A successor may treat empirical reference/contact as primitive only if it explicitly records:

```text
PHYSICAL_REFERENCE_PRIVILEGE = PRIMITIVE_OR_EXTERNALLY_ANCHORED_AT_CURRENT_SCOPE
GRAMMAR_DERIVATION_OF_REFERENCE_PRIVILEGE = NOT_CLAIMED
INTERFACE_COMPLETENESS = NOT_AUTOMATIC
PHYSICAL_EQUIVALENCE = NOT_DERIVED_BY_FORMALISM_ALONE
```

### T6 — Null distinction test

The successor must still differ from the null in which an independent physical law set selects the substantive physical possibility space.

If all empirical/modal selection has already entered through the anchor, there is no remaining strong PGH program.

### T7 — Source-gap test

A source gap may block adjudication only if a concrete missing literature question is identified whose answer could change the status classification. General philosophical discomfort is not a source gap.
