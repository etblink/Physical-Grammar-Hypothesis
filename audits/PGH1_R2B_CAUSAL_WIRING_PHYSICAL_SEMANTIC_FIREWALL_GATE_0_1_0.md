## Executive result

`PGH-GRAM-0008` can receive a minimal operational model-class realization semantics without assigning physical causal ontology to its graph and without selecting numerical response kernels through semantics.

The qualified bridge maps the **entire** formal grammar model class, under a fixed representation relabeling, to a candidate empirical joint-response model class for three prospective record-valued variables.

Because the semantic map adds no extra model selection, every grammar-level model-class theorem transfers to every realized candidate empirical model.

Thus the formal conditional-independence theorem

\[
A\perp C\mid B
\]

becomes the conditional candidate empirical restriction

\[
\boxed{\mathcal A\perp\mathcal C\mid\mathcal B}
\]

for any later separately preregistered empirical instantiation.

No real-world variables have been selected and no data have been examined.

## PGH-DER-0031 — restriction transfer

If every formal grammar model satisfies property `P`, and `J` transports the entire model class without selecting a proper subset or adding law content, then every realized model `J(p)` satisfies the transported property `J(P)`.

Applying this to `PGH-DER-0029` gives the prospective empirical conditional-independence restriction.

This is a conditional semantic theorem. It does not assert that any actual physical system instantiates the bridge.
