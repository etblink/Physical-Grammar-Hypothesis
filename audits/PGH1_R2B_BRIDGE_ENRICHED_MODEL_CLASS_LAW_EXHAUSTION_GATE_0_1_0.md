## Executive result

1. a formal primitive bridge candidate; and
2. a minimal law-free empirical process role for that bridge.

But the bridge-enriched grammar does not constrain the bridge interpretation enough to derive a response law.

## T1 — deterministic universal realizability

Fix finite nonempty `R_c` and set

\[
Y_r=1
\]

for every record label.

Then there is a canonical bijection

\[
\phi:\coprod_{r\in R_c}1\xrightarrow{\cong}R_c.
\]

Let

\[
f_c:X_c\to R_c
\]

be arbitrary.

Define the interpretation of the bridge generator by

\[
\hat n_c=\phi^{-1}\circ f_c.
\]

Then summand-tag pushforward gives exactly

\[
\phi\circ\hat n_c=f_c.
\]

Therefore every deterministic response function is realized.

Because `Set` has finite coproducts and finite products, this is a lawful model control for both:


## T2 — relational support universal realizability

In `Rel`, again identify

\[

\]

For arbitrary

\[

\]

\[

The tag pushforward is exactly `K_c`.

Thus the cocartesian bridge-enriched syntax realizes every response-support relation in this finite relational control.

This is an expressivity theorem, not a claim that relational membership is physical possibility.
