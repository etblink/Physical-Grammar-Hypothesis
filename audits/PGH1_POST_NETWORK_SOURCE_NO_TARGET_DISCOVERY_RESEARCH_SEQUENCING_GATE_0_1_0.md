## Route adjudication

### R1 — expand target discovery

```text
VERDICT = NOT_QUALIFIED_NOW
```

The general methodological intuition that structured registries can provide better coverage is reasonable, but a scientifically usable expansion requires concrete universe/origin rules that are not already canonical. Designing those rules because the first finite search was empty would be post-result method construction.

R1 is not declared impossible forever. It is simply not currently earned.

A future target-discovery methodology developed independently—for example as part of a general cross-project empirical-interface registry project whose design does not depend on PGH target yield—could later be adjudicated on its own merits.

### R2 — suspend active empirical pursuit

```text
VERDICT = QUALIFIED
```

This route preserves the exact candidate and makes the least new scientific commitment.

The candidate may later re-enter target discovery only if:

1. a qualifying interface arises independently in ordinary scientific work; or
2. a separately developed target-discovery methodology gains independent provenance not derived from the need to find a PGH target.

Any such later operation must re-freeze contamination/provenance against everything known at that future date.

### R3 — retire or downgrade candidate for instantiation failure

```text
VERDICT = REJECTED
```

The post-Kp admission standard requires a complete prospective `I`; it does not require that an eligible public target already be known at admission.

`PGH-OBJ-0052` explicitly entered status `TARGET_DISCOVERY_ELIGIBLE_CANDIDATE_PACKAGE`, not `TARGET_ALREADY_AVAILABLE_PACKAGE`.

The original target-selection protocol also contemplates an uninstantiated empirical test when no target survives selection.

Therefore failure to find a target in one finite search does not satisfy a pre-existing candidate-retirement condition.

```text

```

The repository contains broad long-standing open questions, especially `PGH-Q-0017` concerning whether grammar can perform substantive physical selection after a physical reference boundary is fixed.

However, no specific queued post-OP-0110 operation predating the no-target result uniquely controls the next step. Choosing one merely to remain active would add discretionary sequencing.

Because R2 qualifies and the preregistered least-commitment order prefers suspension over optional upstream work, R4 is not selected.

This does not close those open questions.
