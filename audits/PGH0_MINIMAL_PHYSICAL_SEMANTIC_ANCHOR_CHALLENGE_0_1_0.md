The challenge identifies a nontrivial middle layer between pure formal equivalence and a full physical response law.

A **context/record interface** can specify which formal contexts are interpreted as probes/interfaces and which terminal labels are interpreted as records, while leaving the response behavior to the candidate grammar/evaluator.

This is enough to define anchor-relative observational profiles and distinguishability without putting the response table into the anchor.

It is not enough to establish that the chosen contexts or record map are physically fundamental, complete, unique, or representation-independent.

## 5. S4 — Context/record interface

### Schema

Let:

- `X` be candidate structures/states presented to a grammar;
- `C` be a family of one-hole formal contexts selected only as interface/probe types;
- `T` be terminal/output labels generated by evaluation;
- `R` be physical record labels;
- `rho:T_R→R` be a partial interpretation of designated terminal labels `T_R subseteq T` as records;
- `e:C×X→T` be the candidate grammar/evaluator response map, not part of the anchor.

The semantic anchor is

\[
A=(C,R,\rho).
\]

Where defined, the record profile of `x` under grammar `e` is

\[
O_{A,e}(x)(c)=\rho(e(c,x)).
\]

Define anchor-relative indistinguishability:

\[
x\sim_{A,e}y
\iff
O_{A,e}(x)=O_{A,e}(y).
\]

### Acceptance audit

```text
A1_NOT_A_FULL_LAW_SET = PASS_AT_SCHEMA_SCOPE
A2_NOT_DEFINED_BY_TARGET_EQUIVALENCE = PASS_AT_SCHEMA_SCOPE
A3_SUPPORTS_NONTRIVIAL_DISTINGUISHABILITY = PASS_WHEN_COMBINED_WITH_GRAMMAR
A4_REUSABLE_ACROSS_MULTIPLE_CANDIDATE_GRAMMARS = PASS_FOR_SHARED_INTERFACE
A5_DOES_NOT_ENCODE_RESPONSE_OR_DYNAMICS_TABLE = PASS
A6_DOES_NOT_ENCODE_COMPLETE_POSSIBILITY_STRUCTURE = PASS
A7_EXPOSES_FAILURE_CONDITIONS = PASS
A8_SEPARATES_INTERFACE_SEMANTICS_FROM_GRAMMAR_RESPONSE = PASS
OVERALL = QUALIFIED_FORMAL_SCHEMA
```

The qualification is deliberately limited to **formal feasibility**.

### Finite shared-anchor witness

Take:

```text
X = {x,y}
C = {c}
T = {u,v}
R = {0,1}
rho(u)=0
rho(v)=1
```

Hold this same anchor fixed.

Evaluator `e_same`:

```text
e_same(c,x)=u
e_same(c,y)=u
```

Then:

```text
O(x)=0
O(y)=0
x ~_(A,e_same) y
```

Evaluator `e_split`:

```text
e_split(c,x)=u
e_split(c,y)=v
```

Then:

```text
O(x)=0
O(y)=1
x !~_(A,e_split) y
```

The same semantic anchor therefore permits two grammars with different physical-record behavior.

Consequently the anchor does not determine the response law.

### Nontrivial partition witness

Under `e_split`, the anchor-relative equivalence partition is:

```text
{x}
{y}
```

Under `e_same`, it is:

```text
{x,y}
```

Thus the anchor is not merely decorative vocabulary; combined with grammar-generated response it supports nontrivial distinguishability.

### Remaining physical burden

The schema still requires physically motivated choices of:

```text
WHICH_CONTEXTS_COUNT_AS_PROBES
WHICH_TERMINALS_COUNT_AS_RECORDS
WHAT_RECORD_LABELS_MEAN
```

Nothing in this operation proves those choices are fundamental, complete, representation-independent, or unique.

So S4 advances R1 structurally without solving R1 physically.

\[

This is meaningful progress because the interface semantics and response law are separable.
