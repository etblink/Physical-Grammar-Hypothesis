## 1. T1 — semantic reference is not logically identical to substantive law

The canonical law-free empirical contact signature

\[
\Sigma_E=(C,R,\iota_C,\rho)
\]

was deliberately required to remain fixed while incompatible response evaluators vary.

There exist evaluators `e1` and `e2` such that:

```text
SAME_ANCHOR = YES
DIFFERENT_EMPIRICAL_RESPONSE_PROFILE = YES
```

Therefore the anchor does not uniquely determine the empirical response law.

This establishes only the category distinction:

\[
\text{semantic reference/contact}
\neq
\text{substantive response law}
\]

at the present formal scope.

It does not establish that any particular anchor is physically fundamental, complete, or privileged.

```text
T1 = PASS
```

## 2. T2 — the original residual target does not satisfy R1

The canonical `PGH-OBJ-0008` specification requires a physically justified equivalence relation selected by a non-result-directed criterion of physical irrelevance.

```text
PHYSICAL_PRIVILEGE = UNESTABLISHED
```

None of those results actually identifies the physically correct anchor, interface, or equivalence relation.


By the canonical residual specification, this blocks `PGH-OBJ-0008` at the current candidate scope.

## 3. T3 — silent goalpost movement is rejected

One possible rescue would be to redefine R1 after the fact:

> Because a law-free anchor is possible, treat physical privilege as primitive and declare the old R1 solved.

That is rejected.

The original target explicitly required a physically justified irrelevance criterion. Replacing that burden with a primitive anchor changes the claim.

Therefore:

```text
PGH_OBJ_0008 = NOT_RELABELED_SUCCESSFUL
R1 = NOT_RETROACTIVELY_WEAKENED
NEW_OBJECT_IDENTITY_REQUIRED = YES
```

This is why the successor is `PGH-OBJ-0012`, not a silent rewrite of `PGH-OBJ-0008`.

```text
T3 = PASS
```

## 4. T4 — an anchored successor can preserve a real law-exhaustion burden

The fact that semantic reference is primitive does not by itself perform the substantive selection work that R2 is designed to test, provided the anchor remains law-free.

The permitted anchor may identify:

- probe/interface reference;
- record-label reference;
- representation transport of that declared interface.

It may not primitively provide:

- allowed response triples;
- response functions;
- probability or amplitude rules;
- complete possible/impossible histories or tasks;
- target physical exclusion sets;
- empirical-success selection rules masquerading as syntax.

Thus a successor can still make the strong residual demand:

\[
L_{independent}=\varnothing
\]

for **substantive physical law/selection**, while allowing an irreducible semantic contact relation that does not determine that law.

This leaves R2 nontrivial. The grammar must still produce at least one substantive empirical/modal restriction that is not already in the anchor.

```text
T4 = PASS_FOR_CONDITIONAL_SUCCESSOR
```

## 5. T5 — physical privilege is admitted, not derived

The successor must be explicit about the cost of the reformulation:

```text
PHYSICAL_REFERENCE_PRIVILEGE = PRIMITIVE_OR_EXTERNALLY_ANCHORED_AT_CURRENT_SCOPE
GRAMMAR_DERIVATION_OF_REFERENCE_PRIVILEGE = NOT_CLAIMED
INTERFACE_COMPLETENESS = UNESTABLISHED
PHYSICAL_EQUIVALENCE = NOT_DERIVED_BY_FORMALISM_ALONE
```

This is not presented as an explanatory victory.

It is a boundary condition on what the successor asks grammar to explain.

The successor claims, at most:

> Once minimal physical reference/contact is fixed without importing substantive law, grammar may exhaust substantive physical law.

It no longer claims that grammar itself explains why the reference anchor is the physically privileged one.

```text
T5 = PASS_WITH_EXPLICIT_COST
```

## 6. T6 — the successor remains distinct from the null

The live null is structurally:

\[
P=\operatorname{Select}_L(W(G)),
\]

where an independent law-like selector `L` supplies the substantive physical possibility structure.

The anchored successor is different only if its primitive semantic contact remains compatible with multiple incompatible law sets and the grammar supplies the substantive restrictions.

Schematic successor:

\[
A_{ref}+G
\longrightarrow
P,
\]

subject to:

```text
A_REF_CONTAINS_SUBSTANTIVE_LAW = NO
INDEPENDENT_LAW_SET_DOES_SELECTION = FORBIDDEN
GRAMMAR_DERIVED_SUBSTANTIVE_EXCLUSION = REQUIRED
```

If future work discovers that the anchor must be enriched until it already fixes the physical possibility/response structure, the successor collapses into the null and fails.

Therefore the successor is scientifically nontrivial but highly exposed.

```text
T6 = PASS_CONDITIONALLY
```
