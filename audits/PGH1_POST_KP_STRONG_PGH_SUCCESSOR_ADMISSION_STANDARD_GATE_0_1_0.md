## Adjudication

### Why a strict standard is now justified

The post-Kp record has isolated each freedom that can otherwise absorb empirical failure:

```text
FORMAL_MODEL_CLASS_FREEDOM -> G
SEMANTIC_MODEL_SELECTION_FREEDOM -> J
PHYSICAL_APPLICABILITY_FREEDOM -> S
TARGET_ROLE_AND_RECORD_SELECTION_FREEDOM -> I
IMPLEMENTATION_FREEDOM -> EXPERIMENT_PREREGISTRATION
```

The first empirical program already showed that freezing some but not all of these layers is insufficient for maximal reproducibility and unambiguous failure cost.

The source-bound scope adjudication also establishes that a restricted physical domain can be scientifically legitimate while still containing independent physical information. Therefore explicit provenance and claim-class separation are mandatory rather than optional documentation.

### A0 — PASS as mandatory gate

A post-Kp successor must be visibly new. This prevents later revisions from inheriting the evidential status of a pre-revision candidate.

### A1 — PASS as mandatory gate

The original PGH reductions repeatedly showed that rule form and short description are not enough. A future `G` therefore needs selectivity, exclusion/countermodel structure and a universal/nonselective control.

### A2 — PASS as mandatory gate

The semantic bridge must apply to the whole admitted model class. Otherwise the bridge can perform the very model selection being credited to grammar.

### A3 — PASS as mandatory gate

The Kp episode establishes that scope cannot remain implicit. OP-0076 further establishes that universal scope is presently clean while restricted scope requires a separately earned origin.

Outcome B from the preregistration is rejected: independently supplied F3 regime physics does **not** enter strong-PGH candidacy merely because it is explicit and prospective. It changes the claim class unless internalized.

### A4 — PASS as mandatory gate

A scope rule and a target-selection protocol are distinct. `I` must prevent empirical opportunity selection from becoming another response selector.

### A5 — PASS as mandatory gate

A hypothesis with no identity cost for changing its grammar, bridge, scope or instantiation after failure is not meaningfully falsifiable. Revision is allowed, but it creates a new candidate.

### A6 — PASS as mandatory gate

Post-Kp successor design cannot restore prospective status to Kp. This is asymmetric by design:

```text
KNOWN_NEGATIVE_CONSTRAINT_CAN_KILL
KNOWN_COMPATIBILITY_CANNOT_CONFIRM
```

The asymmetry prevents historical data from becoming free positive evidence for a candidate designed after seeing the result.

### A7 — PASS as mandatory gate

Candidate identity must freeze before target discovery. Experiment-specific analysis can be target-tailored only after the target is frozen and before data materialization, under a separate preregistration.

### A8 — PASS as mandatory gate

The two independent Kp implementations agreed on the verdict but differed in null-array details because the original preregistration did not freeze PRNG/sampling mappings. That is enough to require exact stochastic semantics prospectively.

### A9 — PASS as mandatory gate

Strong versus weaker/effective PGH must be an explicit claim-class distinction. This avoids treating ordinary effective-theory domain restriction as if it had already solved strong-PGH law exhaustion.

## Why Outcome A rather than C or D

No new information gap blocks the standard. The standard is a governance/scientific consequence of already-canonical findings.

The program also should not close merely because admissibility is now demanding. The standard preserves a legitimate target-free discovery route while making later empirical credit harder to obtain and easier to interpret.

## Why no scalar score

A0-A9 are hard gates because several failures are noncompensatory. For example, an elegant `G` cannot compensate for result-selected `S`, and perfect reproducibility cannot compensate for semantic model selection.

## Known-result firewall

The admission standard intentionally treats known Kp information as development-history contamination for positive evidence.

A successor generation operation may use the canonical methodological facts:

- the old `A -> B -> C` Kp instantiation failed;
- scope underdetermination was exposed;
- implementation semantics need complete freezing.

It may not search the detailed Kp record for structures, lags, bins, graph edits or target-specific rules that make a successor pass.
