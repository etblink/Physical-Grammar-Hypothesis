## Executive result

The post-Kp problem can now be stated more precisely.

A future empirical PGH candidate cannot be identified only by a formal grammar `G`, nor even by a grammar plus semantic bridge `G+J`, if its physical applicability is left to later target selection. By the time a candidate becomes empirically testable, its provenance must include an explicit applicability status: either universal scope or a prospectively fixed restricted-scope mechanism, together with a prospective instantiation rule.

The gate therefore qualifies the schema

\[
\mathcal C=(G,J,S,I),
\]

as a **candidate-identity accounting standard**, not as a new physical theory.

At the same time, an unrestricted scope predicate is maximally dangerous: it can select any desired subset of empirical systems. Scope therefore inherits the same universal-encoding and selector-origin burden previously found at the rule-language and support layers.

The current 85-source corpus is not sufficient for a source-bound decision among the remaining scope-origin families because it was frozen for representation/coherence, local-to-global constraints, meta-language/logical frameworks, and compositional stochastic/causal process structure—not for domains of theory applicability, effective-regime validity, or physical-scope selection.

## PGH-OBJ-0039 — prospective scope-bearing candidate architecture

A future physical candidate should be accounted for as

\[
\mathcal C=(G,J,S,I),
\]

where:

- `G` fixes the formal grammar/model class and its selective consequences;
- `J` fixes the semantic realization without adding hidden response selection;
- `S` states physical applicability, with `S=TRUE` permitted as an explicit universal-scope special case;
- `I` fixes the prospective system-to-role/record instantiation rule used before outcome inspection.

This does not require every component to be primitive. A successful strong-PGH architecture could derive some components from others. The accounting requirement is that decisive applicability freedom may not remain latent until after empirical outcomes are available.

```text
CANDIDATE_IDENTITY_AT_EMPIRICAL_STAGE = G_PLUS_J_PLUS_EXPLICIT_S_PLUS_I
UNIVERSAL_SCOPE = EXPLICIT_S_TRUE_SPECIAL_CASE
RESTRICTED_SCOPE = REQUIRES_INDEPENDENT_ORIGIN_ACCOUNTING
CONCRETE_SUCCESSOR = NONE
```

## PGH-DER-0032 — unrestricted physical-scope predicate universal encoding

Let `E` be any set of candidate empirical systems or instantiations. For any subset `T subseteq E`, the predicate

\[
S_T(e)=1 \iff e\in T
\]

selects exactly `T`.

Therefore, if the permitted scope language is unrestricted enough to express arbitrary membership predicates, every desired target subset can be redescribed as “the domain where the grammar applies.”

```text
UNRESTRICTED_SCOPE_LANGUAGE = UNIVERSAL_TARGET_SUBSET_ENCODER
SCOPE_RESTRICTION_BY_ITSELF = NOT_EXPLANATORY
SCOPE_PREDICATE_ORIGIN = REQUIRED_FOR_CREDIT
```

This is an elementary formal control with no mathematical novelty claim.

## PGH-FAIL-0037 — auxiliary physical-scope law relocation

If applicability is determined by an independently imposed substantive physical law set `L_S` rather than by grammar-generated structure or a genuinely law-free semantic/reference condition, then the physical selection burden has moved into `S`.

Schematically,

\[
S(e)=\mathrm{Select}_{L_S}(e).
\]

If `L_S` decides which systems receive the grammar's law and which do not, strong-PGH law exhaustion has not been established merely because `G` remains compact inside the selected sector.

This does not make sector-limited models scientifically illegitimate. It means their success would support a weaker/effective modeling claim unless the scope selector itself receives an independent PGH-compatible account.

## Architecture-family adjudication

### F0 — universal physical scope

```text
PROSPECTIVE_FIXABILITY = PASS
RESULT_INDEPENDENCE = PASS
UNIVERSAL_ENCODING_RISK = MINIMAL_AT_SCOPE_LAYER
AUXILIARY_SCOPE_LAW = NONE
FAILURE_EXPOSURE = MAXIMAL
STRONG_PGH_COMPATIBILITY = FORMALLY_CLEAN
STATUS = LIVE
```

Universal scope is the cleanest architecture because it eliminates a separate domain selector. It is also the most empirically vulnerable. A valid counterexample cannot later be excluded by sector narrowing without changing candidate identity.

The gate does not infer that future PGH candidates must be universal; source-bound analysis of restricted scope remains incomplete.

### F1 — grammar/bridge-internal structural scope

```text
PROSPECTIVE_FIXABILITY = POSSIBLE
RESULT_INDEPENDENCE = POSSIBLE_IF_FROZEN
REPRESENTATION_DISCIPLINE = REQUIRED
UNIVERSAL_ENCODING_CONTROL = REQUIRED
SEMANTIC_SMUGGLING_RISK = HIGH
STATUS = FORMALLY_LIVE_NOT_SOURCE_BOUND_ADJUDICATED
```

This is the strongest restricted-scope route in principle: applicability would follow from structure already belonging to the candidate rather than from a separately imposed physical-sector rule.

However, the project has repeatedly found that types, signatures, interface distinctions, and meta-selectors can relocate rather than solve selection. No existing source corpus specifically adjudicates physical applicability generated from candidate-internal structure.

### F2 — primitive law-free observational / semantic scope

```text
PROSPECTIVE_FIXABILITY = POSSIBLE
RESULT_INDEPENDENCE = POSSIBLE
COMPATIBILITY_WITH_PRIOR_SEMANTIC_ANCHOR_CONCESSION = CONDITIONAL
SUBSTANTIVE_LAW_SELECTION_BY_SCOPE = FORBIDDEN
STATUS = FORMALLY_LIVE_NOT_SOURCE_BOUND_ADJUDICATED
```

Prior PGH work permits irreducible law-free physical reference/contact at the semantic boundary. That leaves open a narrow possibility that some applicability facts are likewise reference/measurement facts rather than substantive laws.

But if such facts determine the very physical regularities the grammar is allowed to govern, they cease to be merely semantic. The boundary needs dedicated source-bound treatment.

### F3 — independently established physical-sector / effective-regime scope

```text
SCIENTIFIC_USEFULNESS = PLAUSIBLE
STRONG_PGH_LAW_EXHAUSTION_CREDIT = AT_RISK
INDEPENDENT_PHYSICS_RELOCATION = LIKELY_IF_SCOPE_USES_DYNAMICS_OR_REGIME_LAWS
STATUS = REQUIRES_SOURCE_BOUND_ADJUDICATION
```

A physical theory may legitimately have a domain of validity determined by scale separation, equilibrium, weak coupling, effective degrees of freedom, causal assumptions, or other prior physics. That can be excellent ordinary science.

For strong PGH, however, substantive pre-existing physics used to decide applicability is a potential independent law set. The project lacks a dedicated source corpus on how theory applicability and effective-regime validity are scientifically established, so this distinction should not be settled from intuition alone.

### F4 — higher-level grammar / meta-selector

```text
FORMAL_POSSIBILITY = YES
RELOCATION_CONTROL = ACTIVE
STATUS = CONDITIONAL_NOT_YET_QUALIFIED
```

A higher-level grammar could in principle assign subgrammars to domains. But if that meta-selector is unrestricted, primitively enumerative, or independently law-loaded, the same scope problem reappears one level higher.

This route remains formally live only under the same anti-relocation standards already applied to meta-language selection.

### F5 — named-sector / taxonomy-only scope

```text
PROSPECTIVE_NAMING = POSSIBLE
EXPLANATORY_SELECTION = NONE_BY_NAMING_ALONE
STATUS = NO_PGH_CREDIT_WITHOUT_INDEPENDENT_SCOPE_ORIGIN
```

Naming a sector before testing is better provenance than naming it after failure, but prospective naming alone does not explain why the grammar is physically constitutive there.

### F6 — result-sensitive / fit-defined scope

```text
STATUS = REJECT
```

Any scope defined by the candidate's predicted conditional independence, Markov behavior, fit statistic, residual, or empirical success criterion is result leakage.

## Why Outcome D rather than A

The architecture schema itself qualifies, and some restricted-scope families remain logically possible. But Outcome A would imply that the current source base is sufficient to hand directly to a scope-origin feasibility adjudication.

It is not.

The difference between a scientifically legitimate domain-of-validity condition and an auxiliary independent physical law is central to F2 and F3. The project should not settle that boundary without a corpus designed for it.

## Why Outcome B does not pass

Universal scope is clean but has not been shown to be the only strong-PGH-compatible architecture. F1 and the narrow law-free version of F2 remain formally live.

## Why Outcome C or E does not pass

The universal-encoding and law-relocation controls expose serious failure modes, but they do not prove that every restricted-scope mechanism must fail. No impossibility theorem has been established.
