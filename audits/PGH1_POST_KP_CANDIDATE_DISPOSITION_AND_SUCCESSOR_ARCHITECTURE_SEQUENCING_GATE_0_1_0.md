## Executive result

The scientifically appropriate response to the first empirical failure is not to keep sampling targets under an unchanged candidate whose physical scope was never fixed, and not to immediately engineer a new scope-bearing successor around the failure.

`PGH-GRAM-0008` should therefore leave the active physical-target-testing track under its unchanged identity. Its formal content remains useful: it is a compact, nonuniversal model-class restriction with an explicit countermodel, a complete-DAG universality control, a valid semantic-transfer construction, and a real failed empirical instantiation.

Those facts make it a valuable formal and methodological control. They do not justify further physical predictive credit for the same candidate.

The project should continue only by moving upstream: before another candidate is selected, it should determine what a scientifically admissible architecture would have to contain so that grammar, semantic bridge, and physical scope are prospectively linked rather than assembled in stages after empirical outcomes.

## R1 — continue unchanged PGH-GRAM-0008 to a second target

```text
DISPOSITION = REJECT_AS_PREDICTIVE_ROUTE
```

### C1 — evidential integrity

Fails at the controlling level. A second target would occur only after the first target failed and after the project discovered that the candidate had no predeclared physical domain. Repeating the same target-selection machinery without fixing that scientific identity problem would increase researcher degrees of freedom rather than restore preregistered scope.

### C2 — predictive legitimacy

Fails. `PGH-OBJ-0036` selects test opportunities; it does not establish that every eligible target belongs to a physical domain governed by the grammar. A second metadata-eligible target therefore cannot automatically be counted as a second independent prediction of unchanged `PGH-GRAM-0008`.

### C3 — explanatory progress

Weak. More target outcomes would not answer why the sparse wiring applies physically where it does.

### C4 — auxiliary freedom

Poor. Without a scope rule, every target outcome creates temptation to reinterpret what counts as a relevant instantiation.

### C5 — provenance / option value

Descriptive exploration could be preserved in a separate exploratory program, but that is not the current predictive route and earns no PGH physical credit.

## R2 — retire old candidate and immediately design a scope-bearing successor

```text
DISPOSITION = LIVE_BUT_NOT_PREFERRED_NEXT
RELATIVE_WEIGHT = 0.20
```

This route is methodologically legal if the new candidate receives a new identity and all new scope content is explicitly post-Kp.

However, immediate successor design is unusually exposed to result-conditioned architecture. The project now knows exactly which empirical architecture defeated the old candidate. A designer could, even unintentionally, choose a physical-scope predicate, graph structure, or semantic qualification that excludes Kp-like systems or privileges systems more likely to satisfy the desired restriction.

No current artifact independently supplies the missing physical-scope principle. Therefore direct successor construction is premature.

## R3 — retire old candidate and return upstream before successor selection

```text
DISPOSITION = SELECT
RELATIVE_WEIGHT = 0.70
```

This route best satisfies the weighted criteria and, more importantly, the non-scalar scientific rationale.

### C1 — evidential integrity

Strongest. Kp remains failed, the old candidate is not rescued, and no new scope content is attached to it.

### C2 — predictive legitimacy

Strongest available route. A future candidate can be required to state how physical scope is earned before any next target is selected.

### C3 — explanatory progress

Directly addresses the newly isolated burden. The problem is no longer merely whether a formal grammar excludes models; `PGH-GRAM-0008` already showed that. The unresolved problem is how a formally selective grammar acquires a non-result-directed physical domain and semantic role.

### C4 — auxiliary freedom

Better than immediate successor design because the next operation can map admissible architecture requirements and failure modes without selecting one favorable concrete grammar or physical sector.

### C5 — provenance / option value

Strong. The formal candidate remains available as a control, while any later successor can receive a clean new identity and prospective scope provenance.

## R4 — close or archive strong PGH at current scope

```text
DISPOSITION = LIVE_TERMINATION_CONTROL_NOT_SELECTED
RELATIVE_WEIGHT = 0.10
```

Termination remains scientifically legitimate and must stay live.

It is not selected now because the current evidence does not establish an impossibility theorem for prospectively scope-bearing physical grammars. One candidate instantiation failed, and one important architectural omission was exposed. The project still has a distinct, nonempirical question: whether any candidate architecture can couple formal exclusion, semantic realization, and physical scope without relocating substantive physical selection into an auxiliary selector.

If the upstream architecture-discovery route finds that every admissible scope mechanism either imports independent physical law, is universal/nonselective, or is result-sensitive, termination or substantial downgrade should become the favored disposition.

## Next scientific burden

The next operation should be an upstream, target-free architecture-discovery gate, provisionally named:

```text
PGH1_POST_KP_PROSPECTIVE_GRAMMAR_BRIDGE_SCOPE_ARCHITECTURE_DISCOVERY_GATE
```

Its job should be to classify what a future candidate must prospectively bind together:

1. a formally selective grammar/model class;
2. a semantic realization that does not add hidden response law;
3. a physical-scope or domain-membership rule whose justification does not depend on target outcomes;
4. a provenance rule that forces any candidate-specific scope to be frozen before empirical target discovery;
5. explicit failure controls for scope universality, scope arbitrariness, scope-as-independent-law, and scope-by-result-fit.

The operation should **not** yet select a successor grammar, a named physical sector, or a new empirical dataset.

## Why immediate source intake is not selected

No specific literature gap is yet the controlling problem. The immediate need is to formulate the architecture question precisely enough to know whether a bounded source gap exists. Searching first risks selecting literature around a desired successor story.
