## Executive result

`PGH-DER-0028` establishes that the current bridge-enriched grammar universally realizes arbitrary response structures at the tested atomic level.

The frozen 70-source corpus and completed PGH controls were used to screen eight possible ways of reducing that freedom.

No currently represented family earns immediate R2B constraint selection.

A concrete source gap is material: the corpus lacks a dedicated representative lane for modern categorical probability, Markov categories, causal process theories/Bayesian-network process semantics, and related compositional probabilistic structures in which normalization, conditional independence, causal order, or other response-level constraints may arise structurally across model classes.

This gap is directly relevant to the new problem and could change the next formal constraint choice.

## F1 — doctrine-generated compositional extension

### Disposition

```text
STATUS = FORMALLY_AVAILABLE_BUT_PROPAGATIVE
NEXT_R2B_SELECTION = NO
```

Coproduct-capable doctrines can derive bridge morphisms for composite formal objects from atomic bridge morphisms by universal properties.

This is genuine formal generation, but it does not reduce the unconstrained model freedom of the atomic bridge generators established by `PGH-DER-0028`.

At best it propagates whichever atomic response interpretations the model already supplies.

The physical meaning of a composite context/output object would also require a separate semantic bridge.

## F2 — naturality / equivariance

### Disposition

```text
STATUS = PROMISING_CONDITIONAL
BLOCKER = NONTRIVIAL_CONTEXT_TRANSFORMATION_STRUCTURE_NOT_YET_EARNED
```

Naturality can produce powerful commuting constraints only relative to a nontrivial transformation category/functorial assignment.

The current law-free anchor supplies context and record roles but no physically privileged nontrivial context-transformation category.

With a discrete base, naturality is vacuous.

Choosing transformations because they enforce desired response relations would merely relocate the law.

`PGH-FAIL-0002` remains controlling: representation covariance must not be strengthened into substantive automorphy without separate justification.

## F3 — coherence / rewrite constraints

### Disposition

```text
STATUS = MATURE_FORMAL_FAMILY_BUT_UNSELECTED
```

The frozen coherence/rewrite corpus confirms that diagram equations and convergence conditions can constrain formal systems.

But an arbitrary chosen equation involving `n_c` can encode a desired response relation just as an arbitrary predicate or formation table can.

Only equations forced by independently fixed doctrine or generative structure can receive explanatory credit.

No such nontrivial bridge equation is currently forced.

The frozen SG1 corpus confirms that local compatibility can fail to extend globally without a forbidden-global table.
