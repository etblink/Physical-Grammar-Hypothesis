## 1. What exactly has been refuted?

The original physical package based on the noncollider path

```text

```

with empirical consequence

```text

```

was prospectively refuted at Kp.

Its formal factorization theorem survived, but its frozen Kp physical instantiation failed and remains failed.

### Post-Kp five-package family

The remaining five role-conditioned members of the exhaustive minimal connected three-node/two-edge DAG family were prospectively frozen before HURDAT2 target discovery and then tested together on TGT-008.

```text

PGH-OBJ-0044 = B independent C given A
```

All five were Holm-rejected under both independently frozen calibration architectures.


The cross-target qualification matters. The program has exhausted the six-member **candidate-generation architecture**, not established a universal theorem that every sparse DAG factorization fails on every physical system.

## 3. Why architecture-level retirement is justified

The post-Kp sparse-DAG lane was deliberately exhaustive to prevent graph-repair cherry-picking. Its frozen generation rule enumerated, for each missing pair among `{A,B,C}`, both collider and noncollider path classes with fixed role labels.

That finite rule produced exactly six Markov-distinct role-conditioned packages.

Before HURDAT2, one member was already dead from Kp and the other five were carried forward without empirical ranking. After HURDAT2, no untested member of that frozen minimal-path family remains.

A proposal to continue active positive-credit search inside the same architecture would now need at least one of:

```text
NEW_ROLE_EMBEDDING
NEW_PHYSICAL_SCOPE
NEW_SEMANTIC_BRIDGE
NEW_TARGET_DOMAIN_PRIVILEGE
NEW_GRAPH_STRUCTURE_OUTSIDE_THE_FROZEN_MINIMAL_PATH_ENUMERATION
```

Each would create a new candidate identity. More importantly, if introduced because the six existing packages failed, it would be exactly the kind of result-directed rescue the project has prohibited since Kp.

Architecture-level retirement is therefore a **sequencing conclusion**, not a universal mathematical no-go theorem:

```text
MINIMAL_THREE_ROLE_TWO_EDGE_DAG_PATH_ARCHITECTURE
= RETIRED_FROM_ACTIVE_POSITIVE_STRONG_PGH_SUCCESSOR_SEARCH
```

Permitted retained roles are:

```text
FORMAL_REFERENCE
METHODOLOGICAL_CONTROL
NEGATIVE_CONTROL_IF_SEPARATELY_PREREGISTERED
HISTORICAL_EXAMPLE_OF_COSTLY_FALSIFIABILITY
```

Reopening the architecture in the future would require genuinely new, independently motivated theory that was not extracted from Kp/HURDAT2 residual behavior.

## 4. What did A0-A9 accomplish?

The post-Kp admission standard did **not** fail.

```text
A0_A9_AS_TRUTH_OR_PLAUSIBILITY_FILTER = NEVER_CLAIMED
A0_A9_AS_ADMISSIBILITY_AND_ANTI_LEAKAGE_FIREWALL = SUCCEEDED
```

It accomplished several scientifically important things:

1. froze complete candidate identities before target discovery;
2. prevented Kp pattern mining from selecting the successors;
3. made scope explicit;
4. prevented semantic model selection;
5. made failure costly;
6. forced exact stochastic implementation semantics;
7. allowed a genuinely prospective common-target test;
8. preserved the negative result without in-place repair.

The fact that all admitted candidates failed is not evidence that the standard malfunctioned. A scientific admissibility standard should permit false hypotheses to be tested cleanly.

However, the episode exposes a distinction that future sequencing must keep explicit:

```text
ADMISSION != THEORETICAL_MOTIVATION
ADMISSION != PRIOR_PLAUSIBILITY
ADMISSION != ARCHITECTURE_SELECTION
```

A0-A9 establishes that a candidate may be tested without leakage; it does not supply a reason to expect its primitive selective structure to describe nature.

No A0-A9 rule is amended in this operation. Any later proposal for an additional architecture-selection requirement must be justified target-free and may not be tuned to HURDAT2.

## 5. What happened to the primitive-wiring strategy?

The sparse-DAG family was scientifically legitimate because fixed primitive wiring can constitute a selective grammar without requiring an infinite meta-derivation.

But legitimacy as primitive candidate content is not physical support.

The empirical sequence now says:

```text
FORMAL_SELECTIVITY_FROM_PRIMITIVE_SPARSE_WIRING = DEMONSTRATED
CLEAN_PHYSICAL_EXPOSURE = DEMONSTRATED
EMPIRICAL_SUCCESS_OF_THE_MINIMAL_SPARSE_WIRING_FAMILY = NONE
```

This weakens the case for continuing to search by enumerating simple primitive wiring motifs and then asking nature which one survives.

The project should return to the harder upstream question: what target-free principle, if any, gives physical reason for a selective grammar architecture rather than merely making it finite and falsifiable?
