## Executive result

A primitive bridge/internalization hypothesis need not itself be meta-derived from a deeper bridge principle in order to enter formal candidacy.

But it must survive the same kind of anti-encoding discipline that PGH now applies to primitive grammars.

The gate qualifies a strict bridge-candidate standard and admits one bounded candidate family:

\[
\boxed{n_c:X_c\to\coprod_{r\in R_c}Y_r}
\]

for response-underdetermining typed fibers `R_c` and grammar doctrines with finite coproducts.

This candidate adds a generic cross-type process without specifying or forcing an individual component response arrow.

No physical meaning is assigned to the process or coproduct.

## I3 — coproduct aggregate-output process

For a finite multi-element typed fiber define

\[
O_c=\coprod_{r\in R_c}Y_r
\]

and add one generic process

\[
n_c:X_c\to O_c.
\]

No component edge is primitive.

### Non-component theorem

For every chosen component `Y_i`, interpret in `Set`:

\[
X_c\mapsto1,
\quad
Y_i\mapsto\varnothing,
\]

with at least one other summand mapped to `1`.

The coproduct remains inhabited and `n_c` can be interpreted, while no function

\[
1\to\varnothing
\]

exists.

Therefore no individual `X_c->Y_i` is forced.

This is recorded as:

```text
PGH-DER-0026 = COPRODUCT_AGGREGATE_RESPONSE_NONSELECTION
```

### Information-content comparison

There is no general natural equivalence

\[
Hom(X,\coprod_iY_i)\cong\prod_iHom(X,Y_i).
\]

For the two-summand Set witness `X=1`, `Y0=empty`, `Y1=1`, the left side is nonempty and the right side empty.

Thus the generic coproduct process is not information-equivalent to the component-arrow tuple.

### Response underdetermination

Therefore the candidate remains response-underdetermining at formal semantic scope.
