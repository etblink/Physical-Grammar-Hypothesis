## Executive result

The gate distinguishes two questions that must not be collapsed:

1. can a fixed compositional doctrine generate structural permissions rather than list them? — **yes**;
2. does accepted PGH structure select the doctrine that generates those permissions? — **no at current scope**.

The test ladder gives a strict hierarchy.

## T0 — bare strict monoidal composition

Let `FMon(A,B)` be the free strict monoidal category on object-generators `A,B` with no nonidentity morphism generators.

Objects are tensor words. The only morphisms are identities on identical words.

Therefore there are no morphisms

\[
A\to A\otimes A,
\qquad
A\to I,
\qquad
A\otimes B\to B\otimes A.
\]

Thus bare tensor/composition does not generate copy-like, discard-like, or exchange-like permissions.

```text
BARE_MONOIDAL_COPY = NO
BARE_MONOIDAL_DISCARD = NO
BARE_MONOIDAL_EXCHANGE = NO
```

This result is frozen as `PGH-DER-0017`.

## T1 — symmetric monoidal composition

Pass to the free symmetric monoidal category on the same colored generators and no arity-changing morphism generators.

Symmetry supplies

\[
\sigma_{A,B}:A\otimes B\to B\otimes A.
\]

But symmetric coherence morphisms preserve the multiset and number of generating wires. Hence there is still no morphism

\[
A\to A\otimes A
\]

or

\[
A\to I.
\]

So:

```text
SYMMETRIC_MONOIDAL_EXCHANGE = YES
SYMMETRIC_MONOIDAL_COPY = NO
SYMMETRIC_MONOIDAL_DISCARD = NO
```

Symmetry generates one structural permission only because symmetry is part of the supplied doctrine.

## T2 — cartesian composition

Let a category have finite products.

For every object `A`, the product universal property gives a unique diagonal

\[
\Delta_A=\langle 1_A,1_A\rangle:A\to A\times A
\]

with

\[
\pi_1\Delta_A=1_A=\pi_2\Delta_A.
\]

A terminal object gives a unique map

\[
!_A:A\to 1.
\]

The product universal property also gives the canonical exchange isomorphism

\[
\sigma_{A,B}=\langle \pi_2,\pi_1\rangle:A\times B\to B\times A.
\]

These maps are natural and require no object-by-object lookup table once finite-product structure is fixed.

```text

CARTESIAN_DISCARD_LIKE_TERMINAL_MAP = CANONICAL
CARTESIAN_EXCHANGE = CANONICAL
GENERATED_NOT_LISTED = YES_RELATIVE_TO_CARTESIAN_DOCTRINE
```

This result is frozen as `PGH-DER-0018`.

## T3 — cocartesian plurality control

Finite coproducts give a dual canonical package:

\[
\nabla_A=[1_A,1_A]:A+A\to A
\]

and

\[
0\to A,
\]

plus coproduct symmetry.

This is structurally different from the cartesian diagonal/deletion package.

Both are generated by universal properties relative to their doctrines.

Therefore:

```text

UNIVERSAL_PROPERTY_DOCTRINE_UNIQUENESS = NO
```

A bicartesian setting can contain both packages, which further shows that existence of canonical maps does not by itself establish which package is fundamental.
