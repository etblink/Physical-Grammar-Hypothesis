# Sources

PGH is not yet operating from a selected or frozen scientific source corpus.

Current status:

```text
SOURCE_BOUND_STATUS = NOT_YET_SOURCE_BOUND
CANONICAL_SOURCE_REGISTER = NONE
FROZEN_SOURCE_CORPUS = NONE
```

This directory reserves a durable location for future source-intake artifacts if and when a separately bounded source program is opened.

Do not treat casual citations, conversational references, search results, or neighboring literature as an admitted PGH source corpus.

A future source-bound transition should establish explicit:

- source-intake purpose;
- source-selection criteria;
- source identity and provenance;
- admission/rejection rules;
- saturation or stopping rules;
- source register;
- corpus-freeze boundary.

Until then, canonical PGH claims should remain explicit about their pre-source-bound status.
