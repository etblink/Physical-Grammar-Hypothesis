FAILURE_ID = PGH-FAIL-0037

## Failure pattern

Suppose a compact grammar `G` generates a selective model class, but a separate substantive physical law set `L_S` determines whether a real system lies inside the domain where `G` applies.

Write

\[
S(e)=\mathrm{Select}_{L_S}(e).
\]

If `L_S` performs substantive physical selection that is not generated by `G` and is not merely law-free semantic/reference structure, then the project has not exhausted physical law in grammar.

The selection burden has moved from the model class to its applicability boundary.

## Why this matters

A sector-limited model can be scientifically excellent while still failing strong PGH.

For example, ordinary physical theories may have regimes of validity specified by independently established scale, coupling, approximation, or dynamical conditions. The present failure record does not reject such science.

It records only the strong-PGH accounting consequence:

```text
INDEPENDENT_SUBSTANTIVE_SCOPE_LAW_PRESENT = YES
GRAMMAR_EXHAUSTS_SUBSTANTIVE_PHYSICAL_SELECTION = NOT_ESTABLISHED
```

## Not triggered by every scope condition

This failure is not automatically triggered by:

- explicit universal scope;
- a scope condition genuinely derived from the candidate grammar/bridge;
- a law-free semantic/reference condition that does not decide substantive physical response structure.

Those possibilities require separate adjudication.
