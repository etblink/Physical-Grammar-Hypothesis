# PGH-FAIL-0021 — Mandatory Meta-Derivation Stopping Rule

## Status

```text
FAILURE_ID = PGH-FAIL-0021
STATUS = FAILED_PRESERVED
FAILURE_CLASS = METHODOLOGICAL_OVERCONSTRAINT
```

## Failed rule

> A candidate grammar is unacceptable unless every selective primitive in it is itself generated from a still-deeper primitive structure.

## Why it fails as a mandatory PGH condition

Canonical anchored PGH takes `G` as the candidate generative grammar and requires substantive law to be generated by `G` rather than by an independent selector.

The canonical nontriviality suite audits what is primitive, whether it universally encodes arbitrary targets, whether it compresses and excludes, and whether consequences are independent and falsifiable. It does not require a meta-derivation of every primitive.

Thus the failed rule adds a stronger requirement not present in the hypothesis.

## What remains valid

The project was right to pursue deeper generation while hidden selectivity was moving between tables, formulas, rule languages, and doctrines.

That pursuit exposed where information lives.

The failure is only the conversion of that useful research strategy into the unconditional rule:

```text
NO_META_DERIVATION => NO_CANDIDATE_GRAMMAR
```

## Correct replacement

A primitive grammar may enter candidacy only under `PGH-OBJ-0020`.

It remains blocked if it is an arbitrary table, target-directed encoding, semantically loaded rule set, or non-falsifiable formalism.
