## Failed claim

> Proper local supports become explanatory once they are generated by compact predicates, equations, types, rewrite rules, or symmetry conditions rather than listed as tuples.

This claim fails without an independently restricted rule language.

## Core reason

`PGH-DER-0014` proves that on finite domains every support has a formula description. A fresh primitive predicate can make that description arbitrarily short.

Therefore neither syntactic form nor raw description length guarantees that the support was generated rather than encoded.

## Family-specific failure modes

### Unrestricted predicates

Any target support can be represented exactly.

```text
CLASS = UNIVERSAL_ENCODING
```

### Freely chosen equations

Equations can provide powerful structural compression in a fixed signature, but freely choosing the signature/equations after seeing the desired support can relocate the support table into the algebraic language.

```text
CLASS = UNEARNED_SIGNATURE_OR_AXIOM_SET
```

### Freely chosen types/interfaces

A type declaration can simply mark exactly the combinations one wishes to admit.

```text
CLASS = ADMISSIBILITY_RELABELED_AS_TYPING
```

### Freely chosen rewrite/coherence rules

A rewrite system can encode which local configurations normalize or count as equivalent. Without prior justification of the rules and equivalences, the selectivity remains input.

```text
CLASS = UNEARNED_REWRITE_META_GRAMMAR
```

### Freely chosen symmetry action

A group action may be designed so that a desired support is invariant. Invariance is meaningful only after the symmetry structure is independently fixed.

```text
CLASS = UNEARNED_SYMMETRY_STRUCTURE
```

## What survives

Restricted rule families can be genuinely non-table-driven **conditional on their rule language being independently fixed**.

The failure does not eliminate equational, typing, coherence, or symmetry mechanisms. It moves the explanatory burden to the origin of the permitted rule language and primitive structure.

## Scientific consequence

The next meta-grammar question is:

\[
\boxed{\text{What fixes the allowed local rule language before physical support data are consulted?}}
\]

A future gate should test whether representation invariance, compositional closure, universal properties, or another independently motivated structural principle can restrict the rule language without reintroducing arbitrary selection.
