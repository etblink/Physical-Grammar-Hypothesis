## Failed family

Three richer empirical-interface proposals fail the strong-PGH no-smuggling requirement when supplied as primitive semantic input.

### 1. Primitive allowed-response relation

If

\[
K\subseteq C\times X\times R
\]

is interpreted as the set of physically allowed probe-state-record combinations, then every tuple outside `K` is already physically excluded before grammar acts.

The possibility boundary is therefore partly encoded in the primitive interface.

### 2. Primitive response distribution

If the interface supplies

\[
p(r\mid c,x)
\]

or an equivalent amplitude/weight/kernel, substantive empirical regularity is already primitive.

A later grammar cannot claim to have derived that same response law unless the kernel is itself generated from weaker input.

### 3. Primitive complete possibility/task set

If the interface supplies the complete set of possible/impossible tasks, histories, transformations, or probe-response combinations, then the physical possibility boundary has already been supplied.

This may be a legitimate starting point for other foundational programs. It is incompatible with strong PGH's specific requirement that substantive possibility selection be grammar-generated rather than independently imposed.

## Explanatory-credit rule

A physical restriction already entailed by primitive semantics cannot simultaneously count as an independent grammar-derived restriction.

```text
PRIMITIVE_SEMANTIC_SELECTION_CREDIT = SEMANTICS
GRAMMAR_DERIVATION_CREDIT_FOR_SAME_SELECTION = NO
```

## Important scope

This failure does **not** say that operational probabilities, constructor-theoretic possibility statements, or empirical laws are illegitimate scientific primitives in general.

It says only that treating them as primitive would weaken or abandon the distinctive strong-PGH law-exhaustion claim unless PGH later derives them from weaker input.

## What survives

The law-free contact signature remains admissible because it can be held fixed while mutually incompatible response laws vary.

The completeness and physical privilege of that signature remain unresolved.
