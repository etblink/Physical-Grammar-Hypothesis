# PGH-FAIL-0028 — Coproduct Bridge Semantic Response Relocation 0.1.0

## Status

```text
DERIVATION_ID = PGH-FAIL-0028

```

## Failed move

Start from the abstract bridge candidate

\[
n_c:X_c\to\coprod_{r\in R_c}Y_r
\]

and choose a concrete deterministic, relational, or stochastic interpretation of `n_c`.

Then read the induced summand-label map, support, or probability distribution as if it had been generated by the abstract grammar itself.

That explanatory-credit move fails.

## Diagnosis

`PGH-DER-0027` shows that concrete interpretations can be pushed forward to response data:

```text
SET_MODEL -> RESPONSE_FUNCTION
REL_MODEL -> ALLOWED_RESPONSE_SUPPORT
STOCHASTIC_MODEL -> RESPONSE_DISTRIBUTION
```

But the same abstract bridge symbol admits incompatible interpretations.

Therefore the particular response structure is not fixed by the abstract grammar at current scope.

## Distinction from the admitted law-free role

This failure does not reject the minimal semantic role:

> `n_c` is a declared empirical process/interface from context `c` to its typed record carrier.

That role remains compatible with incompatible response laws and therefore does not itself specify response.

The failure begins when concrete interpretation data is promoted into physical law and credited to the grammar without a model-class constraint theorem.

## Forbidden explanatory move

```text
CHOOSE_MODEL_INTERPRETATION_OF_n
READ_MODEL_DATA_AS_RESPONSE
CLAIM_RESPONSE_WAS_GENERATED_BY_ABSTRACT_GRAMMAR
```

This is forbidden unless a later theorem proves that the response-relevant feature is invariant across every admissible model of the bridge-enriched grammar.
