# PGH-DER-0014 — Finite Local Predicate Universal Encoding 0.1.0

## Status

```text
DERIVATION_ID = PGH-DER-0014
DERIVATION_STATUS = QUALIFIED_FORMAL
PHYSICAL_CLAIM = NONE
```

## Statement

Let `C` and `D` be finite. For every support

\[
R\subseteq D^C,
\]

there exists a finite propositional formula built only from equality atoms `x_i=d`, conjunction, and disjunction whose model set is exactly `R`.

## Construction

For each `r in R`, define

\[
\chi_r(x)=\bigwedge_{i\in C}(x_i=r_i).
\]

Define

\[
\Phi_R(x)=\bigvee_{r\in R}\chi_r(x).
\]

For `R=emptyset`, use contradiction.

## Proof

If `x in R`, choose `r=x`. Every conjunct in `chi_r(x)` is true, so `Phi_R(x)` is true.

Conversely, if `Phi_R(x)` is true, some `chi_r(x)` is true. Then `x_i=r_i` for every `i in C`, hence `x=r in R`.

Thus

\[
\operatorname{Mod}(\Phi_R)=R.
\]

## Consequence

Replacing an explicit finite support table by an unrestricted local formula does not by itself improve explanatory status.

```text
ARBITRARY_FINITE_SUPPORT = LOGICALLY_DEFINABLE
UNRESTRICTED_PREDICATE_LANGUAGE = UNIVERSAL_ENCODER
```

The explanatory burden moves to the prior restriction of the admissible language, primitives, equations, type constructors, or rule-generation process.

## Compact-symbol corollary

If a language is allowed to introduce a fresh predicate symbol interpreted directly as `R`, then any support may receive a one-symbol description.

Therefore description length is not representation-independent explanatory compression unless the language is independently fixed.

## Relationship to PGH-FAIL-0001

`PGH-FAIL-0001` showed that arbitrary extensional formation can encode arbitrary admissibility.

This derivation establishes the analogous meta-level control:

```text
ARBITRARY_SUPPORT_TABLE -> ARBITRARY_LOGICAL_DESCRIPTION
```

without gaining necessity.

## Limitations

This result does not say all restricted logical or algebraic languages are explanatorily vacuous.

It says only that the phrase “generated by a formula/rule” earns no explanatory credit until the rule language itself is constrained independently of the target support.
