## Definition

A **law-free empirical contact signature** is a tuple

\[
\Sigma_E=(C,R,\iota_C,\rho)
\]

with:

- `C`: formal context/interface tokens declared to carry empirical probe/interface reference;
- `R`: record labels;
- `iota_C`: semantic designation metadata identifying how members of `C` are used as empirical interface tokens;
- `rho`: a partial or total interpretation map from designated terminal/output tokens to record labels.

The signature deliberately contains no response relation, response function, probability kernel, amplitude rule, or complete physical possibility set.

## Law-free criterion

A candidate semantic package counts as law-free at this scope only if it is compatible with at least two empirically incompatible response models while the package itself is held fixed.

Thus, for some candidate states/structures `X`, there must exist evaluators `e1` and `e2` such that

\[
\Sigma_E\text{ is unchanged}
\]

but

\[
O_{\Sigma_E,e_1}\neq O_{\Sigma_E,e_2}
\]

on at least one declared probe/state pair.

This criterion is sufficient to show that the signature does not uniquely determine the response law. It does not prove that the signature contains no other substantive assumptions.

## Forbidden additions

The following are outside the law-free signature if interpreted physically:

\[
K\subseteq C\times X\times R
\]

with membership meaning physically allowed response;

\[
p(r\mid c,x)
\]

or analogous weights;

and any primitive complete list of possible/impossible empirical transformations or histories.

Such structures may later be derived outputs of a candidate grammar. They cannot be counted simultaneously as primitive semantic contact and as grammar-derived physical law.

## Interface completeness firewall

`C` denotes the declared empirical interface under analysis.

It does not assert that every physically possible probe is already included.

```text
DECLARED_INTERFACE_C = YES
COMPLETE_PHYSICAL_PROBE_UNIVERSE_C = NOT_ESTABLISHED
```

## Representation compatibility

The signature may be transported across formal presentations using the commuting conditions of `PGH-DER-0008`.

This preserves record profiles on a declared shared interface when the translation hypotheses hold.

Representation robustness does not make the signature physically privileged.

## Explanatory-credit firewall

If a restriction on empirical response is already entailed by primitive semantic input, PGH may not later count that same restriction as independently generated by grammar.

In particular:

```text
SEMANTICALLY_PRIMITIVE_EXCLUSION
!=
GRAMMAR_DERIVED_EXCLUSION
```

This is an accounting rule, not a novelty claim.
