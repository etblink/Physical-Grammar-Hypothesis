## Gap mechanism SG1

```text
ID = SG1_LOCAL_TO_GLOBAL_COMPATIBILITY_OBSTRUCTION
STATUS = SOURCE_GAP_HIGH_PRIORITY
FROZEN_CORPUS_DEDICATED_COVERAGE = NONE_FOUND
```

Target abstract mechanism:

\[
\forall i:\;L_i\text{ locally admissible}
\quad\text{but}\quad
\nexists G\text{ globally compatible with all }L_i.
\]

This is interesting to R2 because the impossibility of `G` may follow from compatibility structure rather than from an explicit list declaring `G` forbidden.

Future source scope should cover local-to-global/gluing/descent machinery, global-section or contextuality obstructions, and comparison examples of locally consistent but globally unrealizable constraint systems.

No claim is made that these formalisms are physical grammar.

## Cross-family firewall

Every future candidate derived from this map must answer:

1. What input structure is independently motivated?
2. What class of models does the principle exclude?
3. Can an arbitrary target exclusion be encoded by freely choosing that input?
4. Does the principle already state the physical possibility/response law in other words?
5. How does the principle connect to the law-free empirical anchor without that bridge carrying the restriction?
6. What explicit countermodel would falsify the candidate?

Failure on items 3–5 blocks R2 credit.
