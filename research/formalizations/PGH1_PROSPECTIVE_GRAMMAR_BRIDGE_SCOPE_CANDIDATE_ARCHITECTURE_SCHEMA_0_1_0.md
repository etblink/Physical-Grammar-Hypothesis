# PGH-OBJ-0039 — Prospective Grammar / Bridge / Scope Candidate Architecture Schema 0.1.0

## Status

```text
OBJECT_ID = PGH-OBJ-0039
STATUS = QUALIFIED_PROSPECTIVE_CANDIDATE_ACCOUNTING_SCHEMA
PHYSICAL_STATUS = NONE
SUCCESSOR_GRAMMAR = NONE
```

## Purpose

Prevent future empirical PGH candidates from leaving decisive physical applicability freedom unspecified until after target outcomes are known.

## Architecture

At the empirical-candidate stage, use the accounting tuple

\[
\mathcal C=(G,J,S,I),
\]

with:

- `G`: formal grammar / generated model class;
- `J`: semantic realization of formal roles/models as prospective physical records;
- `S`: physical-domain membership/applicability rule;
- `I`: prospective system/record/role instantiation protocol.

The tuple records provenance obligations. It is not a claim that these components are ontologically fundamental or mutually primitive.

## Universal scope

Universal applicability is represented explicitly by

\[
S(e)=\mathrm{TRUE}
\]

for every admissible empirical instantiation `e`.

This eliminates a separate selector and maximizes failure exposure.

## Restricted scope

A restricted `S` receives strong-PGH credit only if all applicable conditions are satisfied:

```text
S_FROZEN_BEFORE_TARGET_DISCOVERY
S_INDEPENDENT_OF_PREDICTED_OR_OBSERVED_RESULT
S_REPRESENTATION_DISCIPLINED
S_NOT_AN_UNRESTRICTED_MEMBERSHIP_TABLE
S_NOT_A_RESTATEMENT_OF_MODEL_FIT
S_NOT_AN_INDEPENDENT_SUBSTANTIVE_PHYSICAL_LAW_DOING_THE_SELECTION
S_ORIGIN_EXPLICIT
```

If `S` is derived from `G` or `J`, that derivation is part of candidate provenance.

If `S` is primitive as a law-free semantic/reference condition, the boundary between reference and substantive physical selection must be separately justified.

## Instantiation protocol

`I` must fix role assignment, record mapping, and target-specific admissibility before the candidate's predicted result is examined.

`I` may operationalize an already fixed `S`; it may not silently create a new scope rule.

## Identity rule

```text
FORMAL_OBJECT_IDENTITY = MAY_REMAIN_G
PHYSICAL_EMPIRICAL_CANDIDATE_IDENTITY = G_PLUS_J_PLUS_EXPLICIT_S_PLUS_I
```

A post-result change to `J`, `S`, or outcome-relevant `I` creates a revised empirical candidate identity even if the formal grammar `G` is unchanged.

## Nonclaims

```text
ONE_CORRECT_SCOPE_ARCHITECTURE_FOUND = NO
SUCCESSOR_GRAMMAR_SELECTED = NO
PHYSICAL_SECTOR_SELECTED = NO
UNIVERSAL_SCOPE_REQUIRED = NO

```

The schema is an anti-ambiguity and anti-rescue accounting standard for future candidate construction.
